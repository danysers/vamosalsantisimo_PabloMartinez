# Propuestas de portada · Vamos al Santísimo

Galería local: `http://localhost:3000/propuestas-inicio`. Cada botón muestra una opción; los enlaces llevan al contenido actual del encuentro y del taller.

Las diez vistas de escritorio están exportadas como PNG de 1440 × 900:

1. `01-noche-dorada.png` — negro, oro y custodia a la derecha.
2. `02-luz-de-altar.png` — marfil y custodia a la izquierda.
3. `03-vino-y-oro.png` — bordó solemne.
4. `04-azul-contemplativo.png` — azul noche.
5. `05-editorial.png` — composición editorial clara.
6. `06-oliva.png` — verde capilla.
7. `07-arco-clasico.png` — pergamino y arco.
8. `08-juntos.png` — custodia junto al retrato existente de Pablo.
9. `09-luz-plena.png` — portada clara y centrada.
10. `10-encuentro.png` — datos del evento destacados.

`contacto-10-portadas.jpg` reúne las diez opciones en una sola lámina. La custodia usa la fotografía original con una máscara de transparencia: los valores RGB de los píxeles visibles se conservaron y solo se añadió el canal alfa. La galería es una vista de propuestas y no cambia la portada oficial.
